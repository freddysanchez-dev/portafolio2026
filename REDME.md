## 🚀 Descripción del Proyecto

Este portafolio ha sido diseñado para mostrar mi experiencia como **Desarrollador Full-Stack**, con énfasis en:

- **Simulación Logística**: Sistema de simulación de eventos discretos para el Puerto de Nueva Orleans.
- **Inteligencia Artificial**: Plataforma de recomendación de ejercicios personalizados con API OpenAI.
- **Desarrollo Web**: Creación de aplicaciones modernas, escalables y con excelente experiencia de usuario.

El sitio está optimizado para ser rápido, accesible y visualmente atractivo, con soporte para modo oscuro/claro.
